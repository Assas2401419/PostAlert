# Product Overview

Postalert is a crowdsourced, real-time incident reporting platform for Jamaica. It combines community-driven reporting (similar to Waze/Citizen) with emergency management capabilities.

## Core Purpose
- Enable citizens (16+) to report incidents with photos, GPS location, and severity ratings
- Provide authorities (police, fire, ambulance, community leaders) with dashboards for monitoring, verification, and response coordination
- Keep communities informed about nearby emergencies in real-time

## Key Features
- Incident reporting with multi-step wizard (category, location, media, severity)
- Real-time map and list feed with filtering
- Community confirmation/dispute system for incident validation
- Authority dashboard for verification and response actions
- Push notifications for nearby high-severity incidents
- Historical trends and analytics
- Strike-based content moderation system
- Offline support with queued submissions

## User Roles
- **Citizen**: Can report and confirm incidents
- **Authority**: Verified officials who can verify, respond to, resolve, or dismiss incidents
- **Admin**: Can approve authority accounts and manage the platform

## Geographic Scope
All incidents must be within Jamaica's boundaries. The platform uses Jamaica's 14 parishes for location filtering and jurisdiction assignment.
